# Portfolio

My personal portfolio site: https://mrunmayi30.github.io/Portfolio/

I'm Mrunmayi, a B.Tech student in Artificial Intelligence. I built this site to put my projects and contact details in one place. It's plain HTML, CSS and JavaScript, with no frameworks.

## What's on it

About me, education, my project ShareSphere (a peer-to-peer rental platform), and a contact form that sends messages to my email through Formspree.

## Files

- index.html: the page
- portfolio.css: styling
- portfolio.js: background animation, typing effect, mobile menu and the contact form
- Mrunmayi_Shirsat.pdf: my resume

## Running it locally

The contact form doesn't work when you open the file directly, so start a small server in the project folder:

    python -m http.server 8000

and open http://localhost:8000.
